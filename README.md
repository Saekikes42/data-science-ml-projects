# Data Science & ML Projects

Учебные проекты по анализу данных и машинному обучению на Python. В репозитории собраны Jupyter Notebook с разведочным анализом, подготовкой данных, обучением моделей и оценкой результатов.

## Проекты

| Ноутбук | Описание |
| --- | --- |
| `bank-customer-classification2025 (Мингазов Н.Ф).ipynb` | Анализ данных клиентов банка и классификация вероятности оттока |
| `IrisClassification(Мингазов Н.Ф.).ipynb` | Многоклассовая классификация набора Iris: KNN, наивный Байес, дерево решений и SVM |
| `Video Game Sales (Мингазов Н.Ф).ipynb` | Исследование продаж видеоигр по годам, жанрам, платформам и регионам |

## Что изучается

- разведочный анализ и визуализация данных;
- обработка пропусков и категориальных признаков;
- обучение моделей классификации;
- оценка качества моделей и анализ ошибок;
- кросс-валидация и подбор гиперпараметров;
- анализ табличных данных с помощью pandas.

## Требования

- Python 3.10 или новее
- Jupyter Notebook или JupyterLab
- pandas, NumPy, Matplotlib, Seaborn, scikit-learn

Установить библиотеки можно командой:

    python -m pip install jupyter pandas numpy matplotlib seaborn scikit-learn

## Запуск

1. Склонируйте репозиторий:

       git clone https://github.com/Saekikes42/data-science-ml-projects.git
       cd data-science-ml-projects

2. Запустите Jupyter:

       jupyter notebook

3. Откройте нужный `.ipynb` и выполняйте ячейки по порядку.

Для ноутбука Iris используется встроенный набор данных scikit-learn. Ноутбукам по банку и продажам видеоигр нужны файлы `Churn_Modelling.csv` и `vgsales.csv` соответственно. Их следует положить рядом с ноутбуками; сами датасеты в репозитории не хранятся.
